Про Git
=======

Git — распределённая система управления версиями, созданная Линусом Торвальдсом
в 2005 году для разработки ядра Linux.

Основные возможности Git:
- хранение истории изменений файлов проекта;
- возможность вернуться к любой предыдущей версии;
- параллельная работа нескольких разработчиков через ветви (branches);
- слияние ветвей и разрешение конфликтов;
- фиксация каждого изменения коммитами (commit) с описанием.

Базовые команды Git:
  git init      - создание нового репозитория;
  git add       - добавление файлов в индекс;
  git commit    - фиксация изменений;
  git branch    - работа с ветвями;
  git merge     - слияние ветвей;
  git push      - отправка изменений на удалённый сервер;
  git pull      - получение изменений с удалённого сервера.

GitHub (https://github.com/) - крупнейший веб-сервис для хостинга IT-проектов
и их совместной разработки. Веб-сервис основан на системе контроля версий Git.
